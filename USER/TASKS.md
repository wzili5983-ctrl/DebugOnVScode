# 添加与控制任务

工程使用协作式调度，TIM2 提供 1 MHz 计时。主循环调用 Tasks_Run()，依次执行已开启任务的 Update(elapsed_us)，参数表示该任务上次执行以来的微秒数。支持最多 8 个任务。

## PA0 按键控制

上电警笛静音。PA0 使用下拉输入，按下为高电平，20 ms 消抖；每次按下切换警笛声音开启/关闭，长按不重复触发。警笛开启后持续鸣响，直到再次按下关闭，不再自动在 5 秒后停止。PF9 呼吸灯由 PE4、PE2、PE3 控制。已删除 PF10 第三任务示例。

## 添加自定义任务

1. 编写 Start(void)、Update(u32 elapsed_us)、Stop(void)。Start 初始化或重置任务状态；Stop 将输出恢复为关闭状态。
2. 将新的 .c 文件加入 Keil 工程，并在 main.c 引入声明这些函数的头文件。
3. 初始化所需外设后，调用：

```c
u8 id;
id = Tasks_Register(My_Start, My_Update, My_Stop);
if (id != TASK_INVALID_ID)
    Tasks_Enable(id, 1);
```

Tasks_Register 返回任务编号，新任务默认关闭；注册失败返回 TASK_INVALID_ID。Tasks_Enable(id, 0) 关闭任务并调用 Stop；Tasks_Enable(id, 1) 开启并调用 Start。无效编号返回 0，成功返回 1。重复开启不会重置正在运行的任务。警笛控制任务保持调度以扫描按键，声音状态在模块内部切换；禁用整个警笛任务会同时停止按键扫描，重新启用后恢复静音待命。

Update 必须快速返回，不能使用 delay_ms、delay_us、阻塞等待或长循环。当前 PF8/PF9 波形由软件输出，新增任务耗时会影响波形；计算密集或阻塞操作需拆成分步状态机。这不是抢占式 RTOS。

TIM2 由调度器独占，PF8 为警笛，PF9 为呼吸灯，PA0 为警笛开关按键（高电平有效），PF10 保持熄灭。Tasks_Init 仅在启动时调用一次；任务注册、启停与 Tasks_Run 均在主循环上下文使用，不从中断调用。主循环不可阻塞超过 TIM2 的计数回绕周期（约 71 分钟）。

## 呼吸灯按键

PE4 加快、PE2 减慢、PE3 停止并熄灭 PF9。三个按键均为上拉输入、低电平有效，20 ms 消抖，长按不连发。上电周期 4 秒，每次加快将周期缩短 0.5 秒，每次减慢将周期延长 0.5 秒，范围 1～8 秒。停止后按加快或减慢键按调整后的速度恢复呼吸。停止键优先，同时按快慢键不调整。停止呼吸时仍扫描按键，不影响 PA0 警笛控制。
